# Клиент Campus Equipment

Здесь будет пользовательский интерфейс системы бронирования оборудования.
Технология клиента будет выбрана в следующих лабораторных с учётом требований курса.
На первом этапе клиент ещё не реализован и не имеет команды запуска.

Планируемые экраны:

- Каталог оборудования с фильтрами по категории и доступности на выбранное время.
- Карточка оборудования и форма бронирования.
- Мои заявки и история бронирований.
- Рабочее место сотрудника: согласование заявок, выдача и возврат.
- Управление оборудованием и пользователями для администратора.

Клиент будет обращаться к серверному API. Проверка прав, доступности техники
и допустимости изменения статуса выполняется на сервере.
